# Other experiments

Tools, visual demos, and language experiments from this account. Each repository has its own setup and implementation details.

- [Eddy](eddy.md) — a WebGL2 fluid-painting playground.
- [Chorus](https://github.com/justalivefornothing/chorus-editor) — a text editor with same-browser tab synchronization and a simulated network lab.
- [Impulse](https://github.com/justalivefornothing/impulse-physics) — a 2D rigid-body physics sandbox.
- [Threadbare](https://github.com/justalivefornothing/threadbare-regex) — a regular-expression engine with animated state transitions.
- [Sprig Lisp](https://github.com/justalivefornothing/sprig-lisp) — a small Lisp interpreter with an environment-tree REPL.
- [Stackle](https://github.com/justalivefornothing/stackle-vm) — an expression language with a bytecode viewer and stack debugger.
- [Fennec-8](https://github.com/justalivefornothing/fennec-8) — an assembler and an 8-bit CPU emulator.
- [Turing Soup](https://github.com/justalivefornothing/turing-soup-rd) — a reaction-diffusion playground.
